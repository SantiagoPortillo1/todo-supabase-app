## 🚀 Acerca del Proyecto

¡Bienvenido a **Todo-Supabase App**! Una aplicación moderna de gestión de tareas construida con tecnologías de vanguardia. Esta aplicación te permite organizar tus tareas diarias de manera intuitiva y eficiente, con autenticación segura y sincronización en tiempo real.

### 🌟 Características Principales

- **Autenticación Segura** - Registro e inicio de sesión de usuarios con Supabase Auth
- **Gestión de Tareas** - Crea, lee, actualiza y elimina tareas fácilmente
- **Interfaz Intuitiva** - Diseño moderno y fácil de usar
- **Tiempo Real** - Actualizaciones instantáneas gracias a Supabase Realtime
- **Totalmente Tipado** - Desarrollado con TypeScript para mayor seguridad en el código
- **Responsive** - Funciona perfectamente en dispositivos móviles y de escritorio

## 🛠️ Tecnologías Utilizadas

- **Frontend**: React.js con TypeScript
- **Backend**: Node.js con Express
- **Base de Datos**: PostgreSQL a través de Supabase
- **Autenticación**: Supabase Auth
- **Estilos**: CSS moderno con Flexbox/Grid
- **Control de Versiones**: Git

## 🚀 Cómo Empezar

### Requisitos Previos

- Node.js (v14 o superior)
- npm o yarn
- Cuenta de Supabase

### Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/tu-usuario/todo-supabase-app.git
   cd todo-supabase-app
   ```

2. Instala las dependencias del frontend y backend:
   ```bash
   # Instalar dependencias del frontend
   cd frontend
   npm install
   
   # Instalar dependencias del backend
   cd ../backend
   npm install
   ```

3. Configura las variables de entorno (consulta `.env.example` en cada directorio)

4. Inicia los servidores de desarrollo:
   ```bash
   # En el directorio backend
   npm run dev
   
   # En otra terminal, en el directorio frontend
   npm start
   ```
